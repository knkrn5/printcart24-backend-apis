# Invoice Template Assets

This directory documents the production assets required for client invoice generation:

- **Logo**: `public/images/assets/printcampus-logo.png`
  - Dimensions: 500 × 500 px (rendered proportionally at 70 × 70 px in template)
  - Format: PNG with transparency
  - Usage: Header brand logo (embedded as Base64 Data URI)

- **Signature**: `public/images/assets/pc-sign.jpg`
  - Dimensions: 1280 × 496 px (rendered at 120 × 45 px in template)
  - Format: JPEG
  - Usage: Authorized Signatory block (embedded as Base64 Data URI)
